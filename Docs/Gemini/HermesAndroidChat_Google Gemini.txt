Вот готовый, четко структурированный промпт для IDE Cursor, сформированный по лучшим практикам разработки на Kotlin (Jetpack Compose, Clean Architecture, Ktor Client).

Вы можете скопировать текст из блока ниже и вставить его напрямую в **Cursor Chat (Ctrl+L / Cmd+L)** или **Composer (Ctrl+I / Cmd+I)**.

### Промпт для Cursor IDE

```text
Создай архитектуру и ключевые Kotlin-классы для Android-приложения, подключающегося к Hermes Agent по протоколу WebSocket.

### Технологический стек:
- Язык: Kotlin
- Сетевой клиент: Ktor Client (Engine: CIO, Plugin: WebSockets, ContentNegotiation, Kotlinx Serialization)
- Асинхронность: Kotlin Coroutines & StateFlow / SharedFlow
- Архитектура: Clean Architecture / MVVM

---

### Требования к реализации и структура кода:

1. DTO Модели (`HermesMessage.kt`):
   - Создай `@Serializable` data-классы для обмена JSON-сообщениями:
     - `HermesRequest`: отправка текста/команд (поля: `event`, `session_id`, `content`).
     - `HermesResponse`: обработка ответов от агента (поля: `event`, `delta` для потокового текста, `tool_call`, `session_id`, `error`).

2. Manger/Client WebSocket (`HermesWebSocketManager.kt`):
   - Реализуй синглтон или менеджер подключения со следующей логикой:
     - Метод `connect(host: String, port: Int, apiKey: String, sessionId: String)`: открытие WSS/WS соединения с передачей Bearer-токена в заголовках (`Authorization: Bearer <token>`).
     - Метод `sendMessage(text: String)`: сериализация и отправка текстового кадра (`Frame.Text`).
     - Автоматический Reconnect: обработка разрыва соединения (Exponential Backoff при сбоях).
     - Поток входящих данных: трансляция входящих событий через `SharedFlow<HermesResponse>` или `StateFlow<ConnectionState>`.
     - Метод `disconnect()`: безопасное закрытие `WebSocketSession`.

3. ViewModel (`HermesChatViewModel.kt`):
   - Управление состоянием подключения (`ConnectionState: Disconnected, Connecting, Connected, Error`).
   - Управление списком сообщений чата (`UIState` с `List<ChatMessage>`).
   - Поддержка Streaming: динамическое обновление последнего сообщения агента по мере поступления токенов (`event == "token"` или `delta`).
