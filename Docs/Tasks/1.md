Создай тестовый консольный скрипт на Node.js (TypeScript или ES Modules) для отладки двустороннего обмена сообщениями с Hermes Agent по протоколу WebSocket.

### Технологический стек и зависимости:
- Node.js (v18+)
- Пакет `ws` (для работы с WebSocket)
- Пакет `dotenv` (для безопасного хранения конфигов и ключей)

---

### Требования к функционалу скрипта (`test_client.mjs` или `test_client.ts`):

1. **Конфигурация:**
   - Чтение переменных окружения: `HERMES_WS_URL` (по умолчанию `ws://localhost:8642/v1/ws/chat?session_id=test_node_session`) и `HERMES_API_KEY`.
   - Передача API-ключа в заголовках соединения (`Authorization: Bearer <HERMES_API_KEY>`).

2. **Обработка входящих данных (Agent → Client):**
   - Чтение и парсинг входящих JSON-сообщений.
   - Потоковый вывод текста: если пришел кадр с `event === "token"` (или `delta`), выводи текст в консоль без переноса строки (`process.stdout.write`).
   - Обработка вызовов инструментов (Skills/Tools): отслеживание event `tool_call` и вывод в красивом виде.
   - Обработка завершения ответа: событие `done` или закрытие генерации (вывод красивого разделителя).

3. **Интерактивный ввод (Client → Agent):**
   - Использование модуля `readline` для ввода команд с клавиатуры прямо из терминала.
   - Формирование JSON-структуры кадра для отправки:
     ```json
     {
       "event": "user_message",
       "content": "<текст_сообщения>"
     }
     ```
   - Завершение работы по команде `exit` или `quit`.

4. **Ошибки и Переподключение:**
   - Обработка событий `error`, `close` и `open` со сбором логов соединения.
